# 🎂 케이크 공방 운영 노트

케이크 가게 사장님이 **주문 · 정산 · 재고 · 원가 · 갤러리 · 고객알림**을 한 곳에서 관리하는 홈페이지입니다.
설치할 것도, 매달 내는 돈도 없습니다. 인터넷 브라우저만 있으면 됩니다.

---

## 1. 어떻게 여나요?

### 방법 A. 파일 하나만 받아서 쓰기 ⭐ 인터넷 없이 · 무료 (권장)

**`케이크공방-운영노트.html`** — 이 파일 **하나만** 있으면 됩니다.
바탕화면에 두고 **더블클릭**하면 바로 열립니다. 설치도, 인터넷 연결도, 회원가입도 필요 없습니다.

- 인터넷이 끊겨 있어도 모든 기능이 동작합니다 (외부에 아무것도 요청하지 않습니다)
- 주문·재고·원가·**사진**까지 전부 컴퓨터 안에 저장됩니다
- 파일을 다른 폴더로 옮기거나 이름을 바꿔도 저장된 자료는 그대로 있습니다

> **크롬(Chrome) 또는 엣지(Edge)로 열어주세요.** 사파리는 파일을 직접 열 때 저장이 막혀 있습니다.
> **시크릿 모드에서는 열지 마세요** — 창을 닫으면 자료가 지워집니다.
> 파일을 연 뒤 **설정 → 저장 상태**가 초록색 `정상` 인지 한 번만 확인하시면 됩니다.

<details>
<summary>이 파일은 어떻게 만들어지나요? (개발자용)</summary>

`index.html` + `css` + `js` 를 하나로 합친 결과물입니다. 소스를 고친 뒤에는 다시 만들어 주세요.

```bash
cd cake-shop
python3 build-standalone.py
```
</details>

### 방법 B. 폴더째 받아서 index.html 열기
`cake-shop` 폴더의 **index.html** 을 더블클릭해도 똑같이 동작합니다.
파일이 여러 개라 관리가 번거로울 뿐, 기능은 방법 A와 같습니다.

### 방법 C. 인터넷 주소로 열기 (휴대폰에서도 쓰고 싶을 때)
GitHub Pages로 올리면 `https://아이디.github.io/저장소이름/cake-shop/` 같은 주소가 생깁니다.

1. GitHub 저장소 → **Settings** → 왼쪽 메뉴 **Pages**
2. Source 를 **Deploy from a branch**, 브랜치와 폴더 `/ (root)` 선택 → Save
3. 1~2분 뒤 안내되는 주소 뒤에 `/cake-shop/` 을 붙여서 접속

> 💡 휴대폰에서 그 주소를 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.
> ⚠️ 컴퓨터에서 쓰던 자료와 휴대폰 자료는 **따로 저장**됩니다. 옮기려면 백업 파일을 쓰세요.

---

## 2. 자료는 어디에 저장되나요?

**사장님 브라우저 안에만** 저장됩니다. 인터넷으로 나가지 않으니 고객 전화번호도 안전합니다.
대신 아래 두 가지를 꼭 기억해 주세요.

| 주의 | 설명 |
|---|---|
| 🔴 브라우저 기록을 지우면 자료도 지워집니다 | **설정 → 백업**을 주기적으로 해주세요 (아래 참고) |
| 🔴 컴퓨터와 휴대폰의 자료는 따로 저장됩니다 | 백업 → 다른 기기에서 불러오기로 옮길 수 있어요 |

### ☁️ 깃허브에 백업하기 (권장)

**설정 → 깃허브 백업**에서 버튼 한 번이면 주문·재고·원가표·**사진까지** 통째로 올라갑니다.
컴퓨터가 고장 나거나 바뀌어도 [깃허브에서 불러오기] 한 번이면 그대로 돌아옵니다. 무료입니다.

> 🚨 **반드시 비공개(Private) 저장소를 쓰세요.**
> 고객 이름·전화번호가 들어 있어서 공개 저장소에 올리면 **누구나 볼 수 있고, 나중에 지워도 깃 기록에 남습니다.**
> 이 프로그램은 공개 저장소로는 저장되지 않도록 막아 두었습니다.

**준비 (한 번만 하면 됩니다)**

1. 깃허브에서 **비공개 저장소**를 새로 만듭니다 → [github.com/new](https://github.com/new)
   - 이름: `cake-shop-data` · **Private 반드시 선택** · Create
2. **토큰(열쇠)** 을 만듭니다 → [토큰 만들기](https://github.com/settings/personal-access-tokens/new)
   - Expiration: `No expiration` (또는 1년)
   - Repository access: **Only select repositories** → `cake-shop-data` 선택
   - Permissions → Repository permissions → **Contents** 를 **Read and write** 로
   - Generate token → 나온 글자를 **복사** (딱 한 번만 보입니다)
3. 앱의 **설정 → 깃허브 백업**에 저장소 이름과 토큰을 넣고 **[설정 저장]**
4. **[🔍 연결 테스트]** 를 눌러 `연결 성공! (비공개)` 가 나오는지 확인

**매일 쓰는 방법** — 주문을 입력한 뒤 **[⬆️ 깃허브에 저장]** 한 번. 끝입니다.
홈 화면에서 백업한 지 3일이 지나면 알려드립니다.

> 💡 **[연결 테스트]에서 "연결하지 못했어요"가 나온다면** — 파일을 직접 열었을 때(`file://`)
> 브라우저 보안정책이 막는 경우입니다. 그럴 땐 설정 화면의 **[🖐️ 손으로 백업하기]** 를 펼쳐서
> 백업 파일을 깃허브 웹사이트에 끌어다 놓으세요. 어떤 환경에서든 확실하게 됩니다.
> (또는 위 **방법 C**처럼 인터넷 주소로 열면 버튼이 정상 동작합니다)

## 3. 화면별 사용법

### 🏠 홈
오늘 픽업 · 내일 준비할 것 · 이번 달 매출 · 보낼 알림 · 재고 부족을 한 화면에 모아 보여줍니다.

### 📝 주문·달력
사장님이 주신 주문서식 그대로 만들었습니다.

> 고객이름 · 연락처 · 픽업날짜 · 주문요청사항 · 가격 · 참고사항

여기에 실제 운영에 필요한 **픽업시간 · 원가 · 예약금 · 주문경로 · 상태**를 더했습니다(모두 선택 입력).
저장하면 **아래 달력의 픽업 날짜 칸에 자동으로 표시**되고, 날짜를 누르면 그날 주문이 자세히 보입니다.

- **[자동계산]** 버튼: 주문요청사항에 적은 내용(예: `생화케이크 2단`)으로 원가·판매가를 자동으로 채워줍니다.
- **[💬 채팅 내용으로 주문 만들기]**: 카톡·문자에 적힌 예약 내용을 복사해서 붙여넣으면 주문 목록으로 만들어 줍니다. (아래 4번 참고)

### 📊 월별정산
매월 1일~말일 기준으로 **주문 전체 리스트 + 픽업날짜 + 매출 + 원가 + 이익**을 한 표에서 봅니다.
위쪽에 이번 달 총매출·총원가·순이익이 요약되고, 아래에는 날짜별 합계와 잘 나가는 케이크 순위가 나옵니다.

**원가는 이렇게 정해집니다.**

1. 주문서에 원가를 적어두었으면 → **그 값** (사장님이 적은 값이 항상 우선)
2. 안 적었으면 → **원가표에서 자동으로 가져옴** (표에 <kbd>원가표</kbd> 표시)
3. 원가표에도 없으면 → <kbd>없음</kbd> 으로 표시하고 어떤 주문인지 알려줍니다

- **[주문서에 저장해 두기]** — 자동으로 가져온 원가를 주문서에 실제로 적어둡니다
- **[🔄 원가 전체 다시 계산]** — 원가표를 고친 뒤, 그 달 주문의 원가를 모두 새 값으로 갱신합니다

**[엑셀(CSV) 저장]** 을 누르면 세무·정산용 파일로 내려받을 수 있습니다 (원가가 어디서 왔는지도 함께 저장).

### 📦 재고
케이크 상자 · 보냉백 · 리본 · 초/장식 · 받침 · 포장지 등을 분류별로 관리합니다.
**➖ ➕ 버튼으로 수량을 바로 조절**할 수 있고, 안전재고 이하로 떨어지면 빨갛게 표시되며 홈 화면에도 알려줍니다.

### 🖼️ 갤러리
그동안 만든 케이크 사진을 올려 한눈에 봅니다. 여러 장을 한 번에 올릴 수 있고,
사진은 자동으로 가볍게 줄여서 저장합니다. 태그(생화, 2단, 웨딩 …)로 걸러 볼 수 있어요.

### 💰 원가표
**사장님이 원가를 직접 적어두는 표**가 중심입니다.

| 메뉴 이름 | 원가 | 판매가 | 이익 | 이익률 |
|---|---|---|---|---|
| 생화케이크 2단 | 62,000 | 145,000 | 83,000 | 57% |

- 표 안의 숫자는 **바로 고쳐 쓸 수 있고**, 고치는 즉시 이익·이익률이 다시 계산됩니다.
- 여기에 적어두면 계산기와 주문서의 **[자동계산]** 이 이 값을 씁니다.

계산기에 적은 내용을 찾는 순서는 이렇습니다.

1. **원가표에 이름이 똑같이 있으면** → 그 원가·판매가를 그대로 (`원가표에서 찾음`)
2. **이름 일부만 있으면** → 옵션 키워드를 적용 (`원가표 + 옵션 적용`)
   - 예: 원가표에 `생화케이크`만 있어도 `생화케이크 2단`을 입력하면 원가를 1.8배로
3. **원가표에 없으면** → 재료로 계산 (`재료로 계산함`)
4. 그래도 없으면 → **[➕ 원가표에 추가]** 버튼이 나옵니다

**🏷️ 옵션 키워드** — `2단` = ×1.8, `생화` = +8,000원 처럼 규칙을 정해둡니다.
**🧈 재료로 계산하기** — 접혀 있는 선택 기능입니다. 원가를 처음 잡아보거나 재료값이 올랐을 때 확인용으로 쓰세요.

### 💬 알림
예약이 들어오면 고객 휴대폰으로 보낼 문자 3종을 자동으로 만들어 줍니다.

| 시점 | 언제 목록에 뜨나요 |
|---|---|
| 🧾 주문 당일 | 주문을 등록한 날 |
| ⏰ 픽업 전날 | 픽업 하루 전 |
| 💐 픽업 후 | 픽업 다음 날 |

**[📱 문자 보내기]** 를 누르면 휴대폰 문자앱이 내용이 채워진 채로 열립니다(보내기만 누르면 끝).
사장님 요금제의 기본 문자를 쓰기 때문에 **추가 비용이 0원**입니다.

- **놓친 알림** — 보낼 때를 지나쳤는데 아직 안 보낸 건은 <kbd>놓침</kbd> 표시와 함께 계속 남습니다
- **순서대로 보내기** — 한 건 보낼 때마다 다음 사람으로 넘어갑니다
- **[📋 카톡용 복사]** — 복사해서 카카오톡에 붙여넣기
- **보낸 기록** — 언제 누구에게 보냈는지 남고, 잘못 눌렀으면 되돌릴 수 있습니다
- **탭 제목 배지** — 보낼 알림이 있으면 브라우저 탭이 `(3) 케이크 공방` 으로 바뀝니다
- **컴퓨터에서 보내기** — 안드로이드는 [메시지 웹](https://messages.google.com/web), 갤럭시는 삼성 메시지로 휴대폰을 연결하면 컴퓨터에서도 무료로 보낼 수 있습니다

문구는 **알림 문구 편집**에서 자유롭게 바꿀 수 있고, `{{고객명}}` `{{픽업일}}` `{{잔금}}` 같은 부분은
주문 내용으로 자동으로 바뀝니다.

### ⚙️ 설정
가게 이름, 기본 인건비, 목표 마진율, **백업/복원**, 예시 데이터, 초기화.

## 4. 채팅 내용으로 주문 만들기

주문서 화면의 **[💬 채팅 내용으로 주문 만들기]** 를 누르고, 카톡·문자·메모에 적힌 내용을 붙여넣으세요.
등록하기 전에 **미리보기에서 하나하나 고칠 수 있습니다.**

### 방법 A. 서식대로 적은 글 (가장 정확)
모달의 **[📋 서식 복사]** 를 누르면 아래 양식이 복사됩니다.

```
고객이름: 김민지
연락처: 010-1234-5678
픽업날짜: 2026-08-11
픽업시간: 14:00
주문요청사항: 생화케이크 2단
가격: 145000
참고사항: 핑크톤
```

- 여러 명이면 **위 서식을 이어서** 붙여넣으면 됩니다 (사람 수만큼 자동으로 나눠집니다)
- `이름`, `전화`, `픽업`, `주문`, `금액`, `메모` 처럼 짧게 적어도 알아듣습니다
- 콜론(`:`) 없이 `이름 김민지 / 전화 010-1111-2222 / ...` 로 적어도 됩니다

### 방법 B. 카톡 대화를 그대로
```
[김하나] [오후 3:12] 안녕하세요 010-3333-2222 이고요 9월 5일 오후 1시에
딸기케이크 1호 찾으러 갈게요 48,000원 맞나요?
```
이렇게 붙여넣으면 → **김하나 / 010-3333-2222 / 2026-09-05 / 13:00 / 딸기케이크 1호 / 48,000원** 으로 정리됩니다.

- `8월 3일`, `2026.08.15`, `8/20` 같은 날짜 표기를 모두 알아봅니다
- 월·일만 있으면 올해로, 이미 지난 날짜면 내년으로 잡습니다
- `오후 2시`는 14:00으로, 오전/오후를 안 적은 `2시`는 픽업 시간대(14:00)로 봅니다
- 원가표에 있는 메뉴면 **원가가 자동으로 채워집니다**
- 같은 사람 + 같은 날짜가 이미 있으면 <kbd>이미 등록된 예약</kbd> 로 표시하고 체크를 꺼둡니다

> 대화가 길거나 어수선하면 못 알아들을 수 있습니다. 그럴 땐 방법 A의 서식으로 정리해서 붙여넣으세요.

## 5. 문자 자동 발송에 대해

지금 방식(버튼 → 문자앱)은 **추가 비용이 0원**입니다. 사장님 요금제의 기본 제공 문자를 쓰기 때문입니다.

**"사장님이 안 눌러도 자동으로 나가는 무료 문자"는 존재하지 않습니다.** 자동으로 하려면:

- 문자 발송 서비스 가입 (솔라피 / 알리고 / NHN Cloud 등)
- **발신번호 사전 등록** (통신사 규정, 1~2일 소요)
- 예약 시각에 문자를 쏘는 작은 서버
- 비용: SMS 약 10~20원, 카카오 알림톡 약 7~10원 (건당)

주문이 많아져서 손으로 보내기 번거로워지면 그때 붙이면 됩니다.

## 6. 폴더 구성 (개발자용)

