# 🎂 케이크 공방 운영 노트

케이크 가게 사장님이 **주문 · 정산 · 재고 · 원가 · 갤러리 · 고객알림**을 한 곳에서 관리하는 홈페이지입니다.
설치할 것도, 매달 내는 돈도 없습니다. 인터넷 브라우저만 있으면 됩니다.

---

## 1. 어떻게 여나요?

### 방법 A. 그냥 파일 열기 (가장 빠름)
`cake-shop` 폴더의 **index.html** 파일을 더블클릭하면 열립니다.
단, 브라우저 종류에 따라 자료 저장이 안 될 수 있어요. (설정 화면에서 "저장 상태"를 확인하세요)

### 방법 B. 인터넷 주소로 열기 (권장 · 무료)
GitHub Pages로 올리면 `https://아이디.github.io/저장소이름/cake-shop/` 같은 주소가 생기고,
**휴대폰에서도 같은 주소로 접속**할 수 있습니다.

1. GitHub 저장소 → **Settings** → 왼쪽 메뉴 **Pages**
2. Source 를 **Deploy from a branch**, 브랜치는 `main`(또는 `master`), 폴더는 `/ (root)` 로 선택 → Save
3. 1~2분 뒤 안내되는 주소 뒤에 `/cake-shop/` 을 붙여서 접속

> 💡 휴대폰에서 그 주소를 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

---

## 2. 자료는 어디에 저장되나요?

**사장님 브라우저 안에만** 저장됩니다. 인터넷으로 나가지 않으니 고객 전화번호도 안전합니다.
대신 아래 두 가지를 꼭 기억해 주세요.

| 주의 | 설명 |
|---|---|
| 🔴 브라우저 기록을 지우면 자료도 지워집니다 | **설정 → 백업 파일 내려받기**를 일주일에 한 번 눌러주세요 |
| 🔴 컴퓨터와 휴대폰의 자료는 따로 저장됩니다 | 한 기기에서 백업 → 다른 기기에서 불러오기로 옮길 수 있어요 |

## 3. 화면별 사용법

### 🏠 홈
오늘 픽업 · 내일 준비할 것 · 이번 달 매출 · 보낼 알림 · 재고 부족을 한 화면에 모아 보여줍니다.

### 📝 주문·달력
사장님이 주신 주문서식 그대로 만들었습니다.

> 고객이름 · 연락처 · 픽업날짜 · 주문요청사항 · 가격 · 참고사항

여기에 실제 운영에 필요한 **픽업시간 · 원가 · 예약금 · 주문경로 · 상태**를 더했습니다(모두 선택 입력).
저장하면 **아래 달력의 픽업 날짜 칸에 자동으로 표시**되고, 날짜를 누르면 그날 주문이 자세히 보입니다.

- **[자동계산]** 버튼: 주문요청사항에 적은 내용(예: `생화케이크 2단`)으로 원가를 자동으로 채워줍니다.
- **[🟢 네이버 예약 가져오기]**: 네이버 예약 화면의 내용을 복사해서 붙여넣으면 자동으로 정리해 등록합니다.

### 📊 월별정산
매월 1일~말일 기준으로 **주문 전체 리스트 + 픽업날짜 + 매출 + 원가 + 이익**을 한 표에서 봅니다.
위쪽에 이번 달 총매출·총원가·순이익이 요약되고, 아래에는 날짜별 합계와 잘 나가는 케이크 순위가 나옵니다.
**[엑셀(CSV) 저장]** 을 누르면 세무·정산용 파일로 내려받을 수 있습니다.

### 📦 재고
케이크 상자 · 보냉백 · 리본 · 초/장식 · 받침 · 포장지 등을 분류별로 관리합니다.
**➖ ➕ 버튼으로 수량을 바로 조절**할 수 있고, 안전재고 이하로 떨어지면 빨갛게 표시되며 홈 화면에도 알려줍니다.

### 🖼️ 갤러리
그동안 만든 케이크 사진을 올려 한눈에 봅니다. 여러 장을 한 번에 올릴 수 있고,
사진은 자동으로 가볍게 줄여서 저장합니다. 태그(생화, 2단, 웨딩 …)로 걸러 볼 수 있어요.

### 🧮 원가계산
`생화케이크 2단` 처럼 적으면 원가를 계산해 줍니다. 세 가지를 미리 등록해 두면 됩니다.

1. **재료 단가** — 무염버터 12,900원 / 1000g → 1g당 13원 (자동 계산)
2. **케이크 종류(레시피)** — 생화케이크 한 개에 들어가는 재료·포장자재
3. **옵션 키워드** — `2단` = 원가 ×1.8, `생화` = +8,000원 처럼 규칙을 정해두면 자동 반영

설정의 마진율을 기준으로 **추천 판매가**까지 알려주고, 그 자리에서 주문서로 옮길 수 있습니다.

### 💬 알림
예약이 들어오면 고객 휴대폰으로 보낼 문자 3종을 자동으로 만들어 줍니다.

| 시점 | 언제 목록에 뜨나요 |
|---|---|
| 🧾 주문 당일 | 주문을 등록한 날 |
| ⏰ 픽업 전날 | 픽업 하루 전 |
| 💐 픽업 후 | 픽업 다음 날 |

**[📱 문자 보내기]** 를 누르면 휴대폰 문자앱이 내용이 채워진 채로 열립니다(보내기만 누르면 끝).
컴퓨터에서는 **[📋 복사]** 로 카카오톡에 붙여넣으세요.
문구는 **알림 문구 편집**에서 자유롭게 바꿀 수 있고, `{{고객명}}` `{{픽업일}}` `{{잔금}}` 같은 부분은
주문 내용으로 자동으로 바뀝니다.

### ⚙️ 설정
가게 이름, 기본 인건비, 목표 마진율, **백업/복원**, 예시 데이터, 초기화.

## 4. 지금은 "반자동"인 두 가지 (그리고 완전 자동으로 가는 방법)

### 🛒 쿠팡 재료 가격
쿠팡은 프로그램이 가격을 자동으로 가져가는 것을 기술적으로 막아두었고, 이용약관에서도 제한합니다.
그래서 지금은 **재료 옆 🛒 버튼 → 쿠팡 페이지 열기 → 가격 복사 → 붙여넣기 → 단가 갱신** 방식입니다(30초).

> **완전 자동으로 하려면?** 항상 켜져 있는 작은 서버(월 5,000원 내외)와 가격 수집 프로그램이 필요합니다.
> 더 안전한 대안으로 **쿠팡 파트너스 API**나 가격비교 사이트의 공개 API를 쓰는 방법도 있습니다.
> 원하시면 이 부분만 따로 만들어 드릴 수 있어요.

### 🟢 네이버 예약
네이버 예약은 로그인해야 볼 수 있어서 프로그램이 자동으로 읽어올 수 없습니다.
지금은 **예약 목록을 복사해서 붙여넣으면 자동으로 정리**해 주는 방식입니다.

> **완전 자동으로 하려면?** 네이버 스마트플레이스 **파트너 API 신청**(사업자 심사 필요) 또는
> 서버에서 로그인 상태를 유지하는 프로그램이 필요합니다.

### 📱 문자 자동 발송
지금은 버튼을 누르면 문자앱이 열리는 방식이라 **완전 무료**입니다.
사장님이 누르지 않아도 정해진 시각에 자동으로 나가게 하려면:

- 문자 발송 서비스 가입 (솔라피 / 알리고 / NHN Cloud 등)
- 발신번호 사전 등록 (통신사 규정, 1~2일 소요)
- 예약 시각에 문자를 쏘는 작은 서버
- 비용: SMS 약 10~20원, 카카오 알림톡 약 7~10원 (건당)

## 5. 폴더 구성 (개발자용)

```
cake-shop/
├─ index.html          앱 화면 틀 + 메뉴
├─ css/style.css       디자인
└─ js/
   ├─ utils.js         날짜·금액·화면 도우미
   ├─ db.js            저장소 (localStorage + 사진용 IndexedDB)
   ├─ seed.js          예시 데이터
   ├─ costcalc.js      원가 계산 엔진 + 재료/레시피/옵션 화면
   ├─ orders.js        주문서 + 픽업 달력 + 네이버 붙여넣기 파서
   ├─ monthly.js       월별 정산
   ├─ inventory.js     재고
   ├─ gallery.js       사진 갤러리
   ├─ notify.js        3단계 고객 알림
   ├─ settings.js      설정 · 백업/복원
   ├─ home.js          홈 대시보드
   └─ app.js           화면 전환(라우터)
```

빌드 도구·설치 과정이 없습니다. 파일을 그대로 열면 동작하도록 순수 HTML/CSS/JavaScript로만 만들었습니다.
